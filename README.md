# 📊 Sales Analytics Dashboard

An interactive sales analytics dashboard built with **Python, Pandas, NumPy, Plotly, and Streamlit**.

This project transforms raw sales data into an interactive dashboard that helps users analyze sales performance across different **time periods, regions, product categories, sub-categories, and products**.

The project follows a modular data-analysis workflow, separating data loading, cleaning, analysis, and visualization logic from the Streamlit application.

## 📌 Project Overview

Sales datasets often contain thousands of records that are difficult to analyze directly.

This project provides an interactive interface where users can filter the dataset and immediately see how those filters affect important business metrics and visualizations.

The dashboard answers questions such as:

- What are the total sales?
- How much profit was generated?
- How many orders were placed?
- What is the overall profit margin?
- Which category generates the most sales?
- Which region generates the most profit?
- Which products generate the highest sales?
- How do sales change over time?
- How does performance change when different filters are applied?

# ✨ Features

## 📅 Interactive Date Filtering

Users can select a custom date range to analyze a specific period.

The dashboard automatically adjusts the sales trend visualization:

- Short date ranges → **Daily Sales Trend**
- Longer date ranges → **Monthly Sales Trend**

The selected end date includes the complete day rather than stopping at midnight.

---

## 🌎 Region Filtering

Users can filter the dashboard by region.

Available regions depend on the dataset and include options such as:

- All
- East
- West
- North
- South

All KPIs, insights, charts, and detailed data update according to the selected region.

---

## 🏷️ Category Filtering

Users can select a product category to analyze its performance.

The filtering affects the entire dashboard, allowing users to investigate category-specific sales and profitability.
